## 🌟 Overview & Canon Wiki Alignment

**Everything Upgrade Tree** is an expansive incremental universe meticulously faithful to the official *Everything Upgrade Tree (EUT)* Wiki specifications. Built on an infinite 2D canvas with smooth panning, zooming, and constellation radar, this release implements all 40 canon nodes (#0d through #40) with strict prerequisite branching, named large numbers up to Quinquinquagintillion ($10^{168}$), and interactive baseplates.

## 🎛️ Interactive Centers & Baseplates

1. **📻 Boombox Audio Deck (#9):**
   - Procedural 4-track Web Audio synth player: *Cosmic Drift* (84 BPM), *Astral Coffee* (78 BPM), *Deep Space Lo-Fi* (90 BPM), and *Singularity Chill* (72 BPM).
   - Rotating cassette reels, animated 10-bar equalizer, volume control, and tape warmth low-pass filter slider.
   - Pinned floating mini-player on the canvas with quick play/pause, next track, and expand controls.

2. **🎚️ Leveling Center (#16):**
   - Architectural leveling system gaining XP from clicks, upgrade purchases, and void donations.
   - XP requirement formula scaling: $100 	imes 	ext{Level}^{1.4}$, discounted by ÷1.5 from #23 and ×0.7 from #32.
   - 4 upgradable perks: **Point Magnet** (+10% ₽/rank), **Research Accelerator** (+10% λ/rank), **Speed Demon** (+2 Walkspeed/rank), and **Kinetic Leap** (+5 Jump Power/rank).

3. **🏺 Unethical Donation Baseplate (#0d):**
   - Void Altar tip jar allowing sacrifices of 100 ₽ up to 100% of current Points.
   - Dynamic Karmic Ranks (*Novice Tipper* → *Obsidian Void Patron*) and procedural philosophical void responses.

4. **🎁 Cosmic Supply Drop Baseplate (#18):**
   - 60-second rechargeable orbital supply capsule granting instant 30-second Points surges and 20-second Research bursts.

5. **🏆 Hall of Records & Leaderboard (#20):**
   - Custom Architect callsign editor, all-time peak points reached, tree unlock completion ratio, clicks, prestiges, and mobility metrics.

6. **👑 Hardcore Matrix Mode (#40):**
   - Endgame prestige tier multiplying all upgrade costs by ×5 for master architects seeking extreme challenge.
